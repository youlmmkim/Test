# Market Data Dashboard

국내외 금리 · 크레딧 · 환율 · 헤지 프리미엄 일별 시계열 대시보드.
의존성 없는 정적 HTML 한 페이지로, 빌드 과정이나 서버가 필요 없습니다.

**197개 계열 · 2001-01-02 ~ 2026-08-21 · 영업일 6,128일 · 관측치 1,045,173개**

| 분류 | 계열 수 | 내용 |
|---|---:|---|
| `RATE` | 71 | 한국·미국·일본·호주·독일 국채 커브, 정책금리, BEI, KRW 스왑 |
| `CREDIT` | 103 | CD·CP·공사채·특수채·은행채·여전채·회사채 (등급 × 만기) |
| `FX` | 9 | 원화 환율 4종, 주요 통화·달러지수 5종 |
| `HEDGE` | 12 | USDKRW·JPYKRW·EURKRW·AUDKRW 헤지 프리미엄 (3·6·12개월) |
| `MACRO` | 2 | VKOSPI, VIX |

## 실행

빌드가 필요 없습니다. 셋 중 아무 방법이나 됩니다.

```bash
# 1. 파일을 그대로 열기 — 데이터를 <script>로 싣기 때문에 file:// 에서도 동작
open index.html

# 2. 로컬 서버
python3 -m http.server 8000

# 3. GitHub Pages — Settings → Pages → Source: GitHub Actions
```

## 화면

- **개요** — 주요 지표 8종의 현재 수준과 1일 / 1개월 / 1년 변동, 국고채
  커브(현재 · 1개월 전 · 1년 전), 국고 10년−3년 및 한·미 10년 스프레드.
- **수익률 곡선** — 한국·미국·일본·호주·독일 커브를 시점끼리 또는 국가끼리
  비교. 최대 4개 시점을 겹쳐볼 수 있고, 국가 비교는 공통 만기 격자에
  선형보간해 한 축에 올립니다.
- **시계열** — 197개 계열을 검색해 최대 8개까지 비교. 단위가 다른 계열을
  고르면 자동으로 지수화(구간 시작 = 100)로 전환합니다.
- **크레딧** — 등급 × 만기 스프레드 매트릭스(동일 만기 국고채 대비, bp).
  셀을 클릭하면 해당 계열의 5년 추이가 열립니다.
- **환율 · 헤지** — 원화 환율과 주요 통화를 나눠 지수화 비교, 통화별
  헤지 프리미엄을 만기별로 비교.
- **데이터 품질** — 계열 카탈로그(커버리지·보정 건수·기간)와 보정 규칙.

## 데이터

`data/` 아래 번들은 비공개 저장소
[`youlmmkim/Data`](https://github.com/youlmmkim/Data)의 ETL이 생성합니다.
`.json`이 아니라 `.js`인 이유는, 브라우저가 `file://`에서 로컬 `fetch()`를
차단하지만 `<script>` 로드는 허용하기 때문입니다. 덕분에 파일을 그냥 열어도
동작합니다.

```
data/manifest.js      빌드 메타데이터 · 커버리지 · 품질 요약     (2 KB)
data/catalog.js       197개 계열 메타데이터                      (70 KB)
data/dates.js         공통 영업일 축                             (78 KB)
data/series/RATE.js   분류별 값 — 화면에서 필요할 때만 로드      (1.8 MB)
data/series/CREDIT.js                                            (2.9 MB)
data/series/FX.js · MACRO.js · HEDGE.js                          (439 KB)
```

개요 탭은 `RATE` · `FX` · `MACRO`만 내려받습니다. 2.9 MB짜리 크레딧
블록은 크레딧 탭을 열 때 처음 로드됩니다.

계열 값은 앞뒤 결측을 잘라낸 `{s: 시작 인덱스, v: [...]}` 형태로 저장되므로,
2024년에 시작하는 헤지 프리미엄은 자기 구간만큼만 용량을 차지합니다.

### 값 보정

벤더 원본은 **미고시 상태를 0으로 인코딩**합니다. 실제 0%와 구분되지 않아
그대로 쓰면 2001~2012년 국고 30년이 0%로 그려집니다. 번들에는 이를 결측
처리한 값이 들어 있고(총 8,848개), 판정 근거와 건수는 **데이터 품질** 탭에
있습니다. 원본은 비공개 저장소에 그대로 보존됩니다.

실제 시장 급변동은 보정하지 않았습니다 — ECB 정책금리의 0% 구간, JGB·UST의
마이너스 금리, 2008년 9월과 2020년 3월 KRW 스왑베이시스 급등은 모두 실제
기록입니다.

## 구조

```
index.html          6개 탭 셸
assets/styles.css   디자인 토큰 (라이트/다크 각각 검증된 팔레트)
assets/charts.js    의존성 없는 SVG 라인차트 · 스파크라인 · 히트맵
assets/app.js       탭별 뷰와 데이터 접근
```

차트 규칙: y축은 언제나 하나(단위가 다르면 지수화하거나 차트를 나눕니다),
색은 순서가 아니라 계열에 붙고, 계열이 2개 이상이면 범례가 항상 있으며,
모든 차트에 표 보기가 있습니다. 카테고리 팔레트는 색각 이상 조건에서
라이트·다크 양쪽 모두 검증했습니다.
